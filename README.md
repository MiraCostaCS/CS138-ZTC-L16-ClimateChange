# Lab 16 - Climate Change + Inheritance

This lab practices class inheritance in Python by modeling different mammal species affected by climate change.

Step 1: Create a Mammal class with attributes for domain, kingdom, and class_type, along with getters and setters for each attribute.

Step 2: Give the Mammal class a __str__ method that returns a readable description of the mammal.

Step 3: Create subclasses such as PolarBear and SnowLeopard that inherit from Mammal and add their own species-specific attributes and behavior.

Step 4: In main.py, create instances of your subclasses and print their information to demonstrate that inheritance is working correctly.

Step 5: Test your program to confirm each subclass correctly inherits and extends the behavior of the Mammal base class.

Make sure your code follows Python style conventions and includes clear comments explaining each class and method.
